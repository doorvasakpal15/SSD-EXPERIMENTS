### Step 11 — Put this code in `sonar_demo.py`

```python
import logging

logging.basicConfig(level=logging.INFO)

PASSWORD = "admin123"


def divide_numbers(a, b):
    try:
        return a / b
    except Exception:
        return None


def check_user(username):
    if username == "":
        print("Username is empty")
    else:
        print("Welcome " + username)


def main():
    username = input("Enter username: ")
    result = divide_numbers(10, 0)

    if result is None:
        logging.error("Division failed")

    check_user(username)


if __name__ == "__main__":
    main()
```

You **do not need to run this program**.

SonarQube analyzes the source code itself.

# 🧠 VIVA — HOW TO EXPLAIN THE EXPERIMENT

### What is SonarQube?

> **SonarQube is a code-quality and security analysis platform that analyzes source code and detects bugs, vulnerabilities, code smells and other quality issues.**

### What did you do?

> **I created a Python project, configured it as a local SonarQube project, installed the Python scanner, analyzed the source code and viewed the results on the SonarQube dashboard.**

### What is SonarScanner?

> **SonarScanner is the tool that analyzes the source code and sends the analysis report to the SonarQube server.**

### What is Quality Gate?

> **A Quality Gate is a set of conditions used to determine whether the analyzed code meets the required quality standards.**

### What does PASSED mean?

> **It means the project satisfied the configured Quality Gate conditions.**

### What can SonarQube detect?

Remember:

**B-V-C-S**

- **B** → Bugs
- **V** → Vulnerabilities
- **C** → Code Smells
- **S** → Security Hotspots

### Why did we use localhost?

> **Because SonarQube was running locally on my own computer rather than on a remote server.**
