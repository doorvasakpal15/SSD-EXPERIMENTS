# 13. Add the CI/CD workflow

Open `security.yaml`.

Paste this:

```yaml
name: Security CI Pipeline

on:
  push:
  pull_request:

jobs:
  security-scan:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout source code
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.x"

      - name: Install Bandit
        run: pip install bandit

      - name: Run Bandit Security Scan
        run: bandit -r .
```

Save it.

### ⚠️ MOST IMPORTANT LINE

Make sure it is:

```yaml
run: bandit -r .
```

The `.` means **scan the current repository**.

# 21. Bandit scans your code

Bandit analyzes:

```text
app.py
```

Your code contains:

```python
subprocess.call(command, shell=True)
```

Bandit can identify this as a security problem.

Therefore you may see:

```text
Low: 2
Medium: 0
High: 1
```

and:

```text
Error: Process completed with exit code 1.
```

### 🚨 THIS IS NOT A PROBLEM

The important distinction is:

### First attempt ❌

```text
bandit -r
```

Bandit couldn't scan because no target was specified.

### Correct attempt ✅

```text
bandit -r .
```

Bandit successfully scanned the repository and **found security vulnerabilities**.

So the red ❌ now means:

> **Security vulnerabilities were detected by the CI security tool.**

That is actually useful for your practical demonstration.

# 25. Important viva answers

### What is CI/CD?

**CI** means Continuous Integration and **CD** means Continuous Delivery/Deployment. They automate software integration, testing, security checking, and delivery.

### What is GitHub Actions?

GitHub Actions is a GitHub automation and CI/CD platform used to execute workflows automatically.

### What is Bandit?

Bandit is a **Python static security analysis tool** that detects common security vulnerabilities.

### Why did you use Bandit?

To automatically identify insecure coding practices in Python code during the CI process.

### What is a workflow?

A YAML file containing instructions for GitHub Actions to execute automatically.

### Why `push`?

To run the security pipeline whenever code is pushed to GitHub.

### Why `pull_request`?

To check code changes before they are merged.

### What does this mean?

```yaml
runs-on: ubuntu-latest
```

It tells GitHub Actions to execute the job on an Ubuntu runner.

### What does this do?

```yaml
uses: actions/checkout@v4
```

It checks out the repository source code into the GitHub Actions runner.

### What does this do?

```yaml
run: pip install bandit
```

It installs Bandit in the CI environment.

### What does this do?

```yaml
run: bandit -r .
```

It recursively scans the repository using Bandit.
