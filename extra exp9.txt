EXP 9
Burp analyzes the **live web traffic generated by your running application**.

### The clean demo your teacher will likely be happy with

**1. Create `app.py`**
```text
SSD EXP 9
└── app.py
```

**2. Run it**
```powershell
python app.py
```

Your Flask app runs at something like:

```text
http://127.0.0.1:5004
```

**3. Open Burp Suite → Proxy**

Use the **Burp Browser** and open that URL.

**4. Demonstrate interception**

Turn:

**Proxy → Intercept → ON**

Submit the login form.

Burp catches:

```http
POST / HTTP/1.1
Host: 127.0.0.1:5004

username=admin&password=admin123
```

Now you can explain the **request, method, headers and parameters**.

**5. Forward the request**

Click **Forward**.

The request reaches Flask and you see the response.

---

### Then your second demonstration

Turn:

**Intercept → OFF**

Now traffic passes normally.

Go to:

**Proxy → HTTP history**

You'll see the requests that were generated.

This is actually a **very good thing to show** because you can say:

> "When interception is OFF, Burp doesn't stop the request, but it still records the HTTP traffic in HTTP History for analysis."

---

### Then Intruder

You can take a captured request and:

**Right-click → Send to Intruder**

That's another Burp feature, but **don't describe Intruder itself as the main interception mechanism**.

For this practical, you can simply demonstrate that the request can be sent to Intruder and inspected/configured there.

Your strongest demonstration is:

```text
Flask application
       ↓
Burp Proxy
       ↓
Intercept ON
       ↓
Capture POST request
       ↓
Inspect request
       ↓
Forward
       ↓
Inspect response
```

Then:

```text
Intercept OFF
       ↓
Traffic passes normally
       ↓
Proxy → HTTP History
       ↓
Analyze requests/responses
```

And optionally:

```text
Captured request
       ↓
Send to Intruder
       ↓
Show request/parameters
```

### So YES ✅

If your teacher asks **"Demonstrate dynamic analysis using Burp Suite"**, showing **Intercept + Forward + HTTP History + optionally Intruder** is a much stronger demonstration than just opening Burp and saying it's installed.

Just remember this line for viva:

> **"Burp Suite acts as an intercepting proxy between the client and server, allowing us to capture, inspect, forward and analyze web traffic while the application is running."**
